## Task 3: Calculator

A calculator built with HTML, CSS and JavaScript.

**Features**

- Addition, subtraction, multiplication and division
- Display screen showing the current number and the running calculation
- Keypad arranged with the CSS grid system
- Decimal numbers, percent, change sign (+/-), delete and clear (AC)
- Chained calculations (for example 2 + 3 + 4)
- A clear "Cannot divide by 0" message instead of a crash
- Keyboard support: digits 0-9, `+ - * /`, `Enter`, `Backspace`, `Escape`
- Responsive layout for phones and desktops

**JavaScript concepts used:** event listeners, if-else statements, operators and loops.

**Files**

- `index.html`: page structure and buttons
- `style.css`: colours, layout and the grid keypad
- `script.js`: event listeners and calculator logic

**Run it:** open `Task3-Calculator/index.html` in a browser.
